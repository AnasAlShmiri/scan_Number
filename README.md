# Scan Number

تطبيق Flutter عربي لمسح بطاقات الأرقام بالكاميرا مباشرة، استخراج رقمين محددين بواسطة OCR، وإضافة كل بطاقة تلقائيًا إلى قائمة محفوظة داخل الهاتف، ثم تصدير الدفعة إلى ملف نصي TXT أو Excel.

## الأرقام المطلوبة

التطبيق يبحث عن:

- رقم طويل من **11 رقمًا** مثل: `00436434838`
- رقم قصير من **6 أرقام** مثل: `228790`

الأرقام الأخرى الموجودة على البطاقة مثل `200` أو `30` لا يتم اعتمادها.

## طريقة العمل

1. اضغط **فتح الماسح** ووجّه الكاميرا نحو البطاقة داخل المربع.
2. ثبّت البطاقة لحظة حتى تتطابق قراءتان متتاليتان للرقمين؛ لا تحتاج إلى التقاط صورة أو الضغط على حفظ.
3. تُضاف البطاقة تلقائيًا إلى القائمة الظاهرة أسفل الكاميرا مع الاحتفاظ بجميع البطاقات السابقة.
4. مرّر البطاقة التالية. لا تُضاف البطاقة نفسها مرة أخرى حتى عند إعادة فتح الماسح.
5. يمكنك إيقاف المسح مؤقتًا واستئنافه من الزر أعلى شاشة الكاميرا.
6. اضغط **تصدير TXT** داخل الماسح أو زر تصدير الملف النصي في الشاشة الرئيسية، ثم اختر حفظ الملف أو مشاركته من نافذة المشاركة.
7. يمكن تعديل الأرقام أو حذف بطاقة من القائمة الرئيسية، والتصدير إلى Excel متاح أيضًا.

يفحص الماسح إطارًا جديدًا كل 120 مللي ثانية عندما يكون OCR متاحًا، دون تكديس الإطارات أو انتظار إضافي بعد حفظ البطاقة. يحتفظ بشرط تطابق قراءتين متتاليتين لتقليل أخطاء القراءة. زمن الالتقاط الفعلي يعتمد على سرعة الجهاز والتركيز والإضاءة.

الملف النصي بترميز UTF-8، ويحتوي كل سطر على الرقم الطويل والرقم القصير مفصولين بعلامة تبويب، مع الحفاظ على الأصفار في البداية. التصدير لا يمسح البطاقات من القائمة.

ملف Excel يحتوي عمودين:

| الرقم الطويل | الرقم القصير |
|---|---|
| 00436434838 | 228790 |

تم حفظ القيم كنص داخل Excel حتى لا تختفي الأصفار الموجودة في بداية الرقم الطويل.

## مميزات التطبيق

- واجهة عربية RTL.
- مسح مباشر بالكاميرا وحفظ تلقائي متتابع دون تصوير يدوي.
- OCR يعمل على الجهاز باستخدام Google ML Kit.
- دعم تصحيح أخطاء OCR الشائعة مثل قراءة `0` على أنها `O`.
- دعم الأرقام العربية `٠١٢٣٤٥٦٧٨٩`.
- عرض جميع البطاقات المحفوظة أثناء المسح وتعديلها لاحقًا من القائمة الرئيسية.
- حفظ محلي دائم باستخدام SharedPreferences.
- منع تكرار الرقم الطويل.
- تعديل وحذف سجل واحد.
- مسح جميع السجلات وبدء دفعة جديدة.
- عداد لعدد البطاقات.
- تصدير جميع السجلات مرة واحدة إلى `.xlsx`.
- تصدير جميع السجلات إلى ملف نصي `.txt` من الماسح أو القائمة الرئيسية.
- مشاركة الملف النصي أو Excel أو حفظه من نافذة المشاركة.

## التشغيل

يتطلب المشروع Flutter حديثًا لأن إصدارات الحزم المستخدمة تستهدف Flutter 3.38.1 أو أحدث.

بعد تنزيل المستودع:

```powershell
git clone https://github.com/AnasAlShmiri/scan_Number.git
cd scan_Number
flutter doctor
flutter pub get
```

ملفات Gradle Wrapper مرفقة بالمستودع. بعد تثبيت الاعتماديات:

```powershell
flutter analyze
flutter test
flutter run
```

## بناء APK

```powershell
flutter build apk --release
```

ستجد APK عادة في:

```text
build/app/outputs/flutter-apk/app-release.apk
```
